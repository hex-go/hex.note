<h3>基本概念</h3><ul><li><p>VxLan：虚拟可扩展局域网，Linux内核原生支持</p></li><li><p>VTEP：VxLAN Tunnel End Point，类似flanneld进程</p><blockquote><p>跟flanneld进程的区别：</p><ul><li><p>S.flanneld封包、D.flannel解包的对象是<strong>UDP报文</strong>；S.VTEP封包、D.VTEP解包的对象是<strong>二层数据帧；</strong></p></li><li><p>flanneld工作在用户态，VTEP在内核态；</p></li><li><p>flanneld，通过目标主机IP + 目标flanneld进程Port送达对端；VTEP通过直连路由规则（flannel进程创建），找到D.容器IP所在的D.主机IP，再通过ARP获得D.主机MAC；</p></li></ul></blockquote></li></ul><p></p><p><strong>本质：利用VxLAN的隧道技术，构建Overlay网桥，承载三层的IP包；VxLAN底层隧道工作在L2，flannel-UDP模式底层隧道工作在L4（UDP）。</strong></p><p></p><p>关键信息：</p><ul><li><p>S.主机 路由规则 S.flannel.1（S.VTEP）</p><blockquote><p></p></blockquote></li><li><p>S.flannel.1 路由规则 获得 D.主机VTEP.IP(对端flannel.1设备的IP)，再结合ARP（<strong>新版本，由flannel进程将arp缓存维护到所有节点</strong>），获得D.VTEP的MAC</p><blockquote><p><span style="font-family: SFMono-Regular, Consolas, &quot;Liberation Mono&quot;, Menlo, Courier, monospace; color: rgb(102, 102, 102); font-size: 13px">Destination     Gateway         Genmask         Flags Metric Ref    Use Iface</span></p><p><span style="font-family: SFMono-Regular, Consolas, &quot;Liberation Mono&quot;, Menlo, Courier, monospace; color: rgb(102, 102, 102); font-size: 13px">10.1.16.0       10.1.16.0       255.255.255.0   UG    0      0        0 flannel.1</span></p><p>目标容器所在的子网，网关IP := 该子网所在主机的VTEP.IP，最终封装后的二层数据帧，通过flannel.1发出。</p></blockquote><ul><li><p><code>D.VTEP.MAC</code> + <code>原始IP包</code>   = 桥内数据帧，不能在宿主机网络传输。再增加 <code>VxLAN报文头 VNI=1</code>  ，</p></li><li><p></p></li></ul></li></ul><p></p>
